# Security Policy

## Intended use

sectools is published for **education and authorized security testing only**. Some
tools (`webrecon`, `certscan`, `pcaptriage` on live captures) interact with or
analyse systems and traffic. Only use them against assets you own or have explicit,
written permission to test. You are responsible for complying with all applicable
laws and agreements.

## Reporting a vulnerability

If you find a security issue in sectools itself, please **do not open a public
issue**. Instead, use GitHub's private vulnerability reporting
("Report a vulnerability" under the Security tab) so it can be addressed before
disclosure. Please include steps to reproduce and the affected version.

## Supported versions

This is a 0.x project; only the latest release receives fixes.
